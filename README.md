# LOOP · 軌道試驗場 v10.0.0

本版以 GameAssets 的 `RailLoopLab-v9-20261118.zip` 為基礎，改用**地圖面積比例**，並加入**近景優先陰影**。可行駛 1～3 圈連續軌道，沿途有跨線高架橋與站旁聚落。Three.js、Rapier、模型與貼圖都已隨包提供。

## 開啟

1. 完整解壓縮 ZIP，保留 `index.html`、`src`、`assets`、`vendor` 的相對位置。
2. Windows 已安裝 Node.js：執行 `START_LOCAL.cmd`。
3. 在 Chrome／Edge 開啟 **http://127.0.0.1:4173/**。

也可在專案資料夾執行 `node server.mjs`；或有 Python 時執行 `python -m http.server 4173 --bind 127.0.0.1`。無須建置、npm install、登入或 API 金鑰。使用支援 WebGL 2／WebAssembly 的現代瀏覽器；請透過 HTTP 開啟。

解壓縮內容可直接放到 GitHub Pages 等靜態主機，請保留 `.nojekyll`。所有網址使用相對路徑，支援網站子目錄。

## 本版功能

- **軌道圈數**可選 1、2 或 3 圈，預設 1 圈。多圈使用同一條閉合路線。三圈時，礦車在始發站依序經過右側、中間、左側月台，最後經高架橋跨回右側。
- **5～15 公里**代表整條連續路線的三維總長。軌距沿途變化，部分地段會分開繞過丘陵。相鄰軌道及高架橋上下層共用同一個地理位置的地形資訊。
- **立體交會**保留 6.2 m 軌面高差，多圈選擇 0 m 起伏時仍會生成必要的跨線坡。縱坡上限為 25‰，站區保持水平。啟用橋隧景觀時，生成器會在合適地段安排共用河谷、各圈的跨河橋及一段穿山隧道。
- **站旁聚落**由外側站屋、步道和依地形挑選的住宅或工務建築組成。同一站區沿各圈設月台，共用站名與聚落。小地圖以較亮的線條標示目前所在圈，並標出跨線高架橋。

- **地形面積比例**可從森林、丘陵、田園、沙漠、鄉村、湖畔、雪地、火山選 1～4 種。比例合計 100%，以地圖的平面面積計算。地表顏色、起伏、植被和小地圖共用地理分布。地形交界有蜿蜒的混合帶，混合帶依權重分配面積。
- **63 款新自然模型**：58 款植物與 5 款岩石。依氣候／水岸安排，保留原始 UV、材質分件、透明裁切與色彩；18 張共用 PNG 避免重複下載與 GPU 貼圖，26 款樹／灌木另有 LOD1。
- **Rapier 行車**：650 kg 分為轉向架與簧上車體，保留原有功率與坡度受力；120 Hz 固定步長、CCD、彈簧阻尼與長距離座標重定基準。車體和動物隨懸吊移動，輪組保持軌道接觸位置。
- **實體物理測試**：「懸吊測試」施加垂直衝量；「前方 80 m 擋車器」可隨時放置／移除，倒車時放在倒車方向。撞擊後推桿自動回中立；左側顯示懸吊位移與撞擊次數。
- **壓力測試**可選 2／3 座車站、11 段 1,000～50,000 物件密度、獨立陰影、解析度、可視距離及三種攝影機。

## 陰影品質

打開標題的「壓力測試設定」，可分別開啟「車輛與設施陰影」及「地景物件陰影」，並選擇陰影品質。

| 品質 | 貼圖 | 投影寬度，地景陰影開啟時 |
| --- | --- | --- |
| 近景優先 | 1024 × 1024 | 160 公尺，保留礦車、設施和主要景物的投影 |
| 廣域高畫質 | 2048 × 2048 | 360 公尺，使用 v9 的陰影範圍 |

近景模式用較小的投影區域維持近處的取樣密度，部分小型石頭與地物以接收陰影為主。場景需要清楚的遠處投影時可選廣域高畫質。匯出紀錄同時保存主畫面的繪製次數／三角形與陰影的繪製次數／三角形，適合用固定種子和相同視角比較。

Rapier 使用受軌道約束的動力學，沿軌里程映射到三維路線。它實際求解受力、關節與碰撞；本版尚未模擬輪緣／鋼軌的完整三維接觸或脫軌。高密度是壓力測試選項，實際 FPS 取決於裝置、解析度、陰影與可視距離。

## 操作

↑／↓ 調整動力推桿，Space 回中立滑行；P 或 Esc 暫停。可拖曳畫面旋轉、滾輪縮放；C 循環追車／駕駛／全景。駕駛視角可拖曳轉頭。推桿平地刻度保留 120 km/h 前進、30 km/h 倒車上限；上下坡仍改變實際車速。分頁移到背景時會自動暫停。

標題改動地形、車種、路長、圈數或坡度時會重建預覽。預覽用 2,000 物件，正式開始時使用所選的密度。遊戲內「匯出測試紀錄」可下載實際設定、各圈起點、交會與月台里程、地圖面積比例、各地形經過的里程、模型計數和 Rapier 診斷。
