# LOOP · 軌道試驗場

使用 GameAssets 既有 Blender → GLB 素材製作的 Three.js 顯示壓力測試。純靜態網頁，不需要打包、不需要 `npm install`、不需要 API 金鑰。Three.js 與所有模型／貼圖已包含在專案，執行時不連接 CDN。

## 執行

請先完整解壓縮，再選擇下列方式之一：

- Windows 已安裝 Node.js：執行 `START_LOCAL.cmd`，以 Chrome / Edge 開啟 **http://127.0.0.1:4173/**。
- 命令列：在專案目錄執行 `node server.mjs`。
- 已安裝 Python：在專案目錄執行 `python -m http.server 4173 --bind 127.0.0.1`，再開啟相同網址。
- 以 VS Code Live Server 或其他靜態 HTTP 伺服器開啟。

瀏覽器需要支援 WebGL 2。請使用 HTTP 網址；直接雙擊 `index.html` 的 `file://` 網址無法載入 ES Modules／GLB。

## 放到 GitHub Pages

1. 將本目錄內的檔案放到你的 repository 根目錄，保留 `index.html`、`style.css`、`src/`、`vendor/`、`assets/`、`asset-manifest.json` 與 `.nojekyll`。
2. 在 repository 的 **Settings → Pages**，選擇從你的分支與根目錄部署。
3. 使用 GitHub Pages 提供的網站網址開啟。GitHub repository 檔案頁面本身不會執行遊戲。

所有資源使用相對路徑，支援 `https://帳號.github.io/專案名稱/` 這類子目錄部署。沒有 build 步驟。`server.mjs`、測試、啟動器與說明檔可一起上傳，也可只部署前述執行所需檔案。

## 玩法

- 標題畫面可指定 A、B 區地形，或選隨機；兩區必須為不同地形。提供森林、丘陵、田園、沙漠、鄉村、湖畔、雪地、火山八種選擇。
- 選擇金橡、青湖或赤銅礦車，軌道長度為 **5–15 公里，每公里一個選項**，車站可選 **2 或 3 座**。
- 場景載入完成後開始秒數計時，同時倒數 **3 秒**。倒數也計入畫面時間。預設推桿為前進動力 42%，倒數結束後逐漸加速出站。
- 右下推桿向上增加正向動力，向下先煞車、再倒退；放開後保持原位置。推桿回到中間為中立滑行，阻力會使礦車逐漸停止。
- **前進最高 120 km/h，倒退最高 30 km/h**。方向與速度連續變化，不會瞬間反轉。礦車受軌道拘束，不模擬側向離軌。
- **↑ / ↓** 調整推桿，**Space** 回中立，**P / Esc** 暫停／繼續，**C** 切換追車／駕駛／全景。
- 追車畫面可拖曳旋轉與滾輪縮放，觸控也可拖動攝影機與推桿。
- 沿線車站不會自動停車，需要自行煞車。路線為封閉循環，正向與倒退都能持續繞行，沒有終點。
- 左下提供暫停／繼續與回到標題。暫停時行駛與計時一起停止；切換到背景分頁也會自動暫停。

## 壓力測試

展開標題的「壓力測試設定」：

| 選項 | 可選設定 |
| --- | --- |
| 地景模型實例 | 2,000 / 8,000 / 20,000 / 50,000 |
| 可視距離 | 300 / 550 / 900 / 1,400 公尺 |
| 像素比上限 | 0.75× / 1× / 1.5× / 2× |
| 動態陰影 | 開啟 / 關閉 |
| 地圖種子 | 留空隨機，或輸入固定字串 |

像素比會受裝置原生 devicePixelRatio 限制。物件數指主要地景模型實例，不含軌道、車站與固定湖畔裝飾。近景車站與礦車可投射動態陰影；大量地景實例不投射陰影。

右上顯示實際 FPS、幀時間、draw calls、三角形數、地景實例數與 1% low。1% low 取最近至多 600 幀中最慢 1% 幀時間平均值換算。FPS 可能受螢幕更新率、瀏覽器垂直同步與電源模式限制。

按「匯出測試紀錄」下載 JSON，包含本次設定、實際路長、物件數及逐秒量測。最多保留最近 14,400 筆（約四小時）紀錄，避免無限繞行累積無限制記憶體。資料只在瀏覽器記憶體與使用者主動下載的檔案內，不上傳伺服器。

比較效能時，請固定 **地形、礦車、路長、種子、物件數、可視距離、陰影、解析度、視窗尺寸與攝影機視角**。全景採用軌道線段 LOD；追車／駕駛才會顯示原始 GLB 軌段，不宜跨視角直接比較 FPS。請從標準設定開始，再逐步加壓。

## 實作方式

- Three.js **0.180.0 / r180**，使用原生 ES Modules 與本機 import map。
- 精選 **64 個 GLB**；只載入當次兩種地形、礦車、車站與鐵軌需要的素材。
- 一單位等於一公尺，路線按弧長縮放至指定的 5,000–15,000 公尺。路徑由有擾動的長橢圓形成，含多次彎折。
- 地圖是 **2D × D**，由左右兩塊約 **D × D** 的等面積地形構成。接縫以寬帶混合地表顏色、高度與植被，邊界微彎且平均不偏移。
- 礦車、鐵軌、地形廊道及小地圖讀取同一份距離取樣表。原始 2 m 軌段以 GPU instancing 鋪設，急彎自動縮短軌段，軌段中點與車行路徑誤差控制在 7 mm 以內。
- 軌頂 y = 0.405 m，雙軌中心距 1.777 m；礦車根節點 y = 0.381 m，車輪依 0.346 m 踏面半徑旋轉。
- 每秒 120 次固定物理步長，以動力、煞車、滾動阻力與速度阻力積分，並限制加速度變化。
- 地景依模型與空間區塊使用 `InstancedMesh`，配合距離剔除、視錐剔除、共用材質／幾何與全景軌道 LOD。
- 回標題與重建場景會釋放舊實例、地形幾何、文字貼圖；資產快取保留可共用的模型資料。
- `assets/provenance/` 保存選用模型的原始 metadata 與來源紀錄。未修改 GameAssets 原始模型；未把 `.blend` 工作檔或整個素材庫放入網頁。

## 檔案

| 路徑 | 用途 |
| --- | --- |
| `index.html`, `style.css` | 標題、HUD、推桿與響應式樣式 |
| `src/core.js` | 路徑、弧長、地形混合及物理 |
| `src/world.js` | GLB 載入、軌道、地形與實例化 |
| `src/app.js` | 遊戲狀態、輸入、攝影機、FPS 與量測匯出 |
| `asset-manifest.json` | 精選素材清單、路徑與尺寸 |
| `assets/` | 模型、縮圖、來源與軌道規格 |
| `vendor/` | Three.js、GLTFLoader 與 MIT 授權 |
| `tests/` | Node.js 自動化測試 |
| `server.mjs` | 僅監聽本機的零依賴預覽伺服器 |

## 驗證

執行 `node --test tests/core.test.mjs tests/assets.test.mjs`。

測試涵蓋十一種路長、閉合與反向繞行、指定種子、2／3 車站均佈、雙地形混合、急彎接軌精度、3 秒倒數、前後速限、平順煞車倒退、中立停止、全部 GLB 的完整性與內嵌資源。瀏覽器互動驗證紀錄見 `VALIDATION.md`。

Three.js 文件：[InstancedMesh](https://threejs.org/docs/#api/en/objects/InstancedMesh)、[GLTFLoader](https://threejs.org/docs/#examples/en/loaders/GLTFLoader)。引擎授權見 `vendor/THREE-LICENSE.txt`，模型來源紀錄保留在各資產 provenance 中。
