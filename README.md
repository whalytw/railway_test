# LOOP · 軌道試驗場 v8.0.0

本版以 v7 為基礎，加入 Quaternius 的 **63 款自然模型**，將原有八種環境改成 **1～4 種、合計 100% 的沿軌道路程混搭**，並以本機 Rapier 0.21.0 進行行車受力、彈簧懸吊與擋車器碰撞求解。Three.js、物理引擎、模型與貼圖都已隨包提供。

## 開啟

1. 完整解壓縮 ZIP，保留 `index.html`、`src`、`assets`、`vendor` 的相對位置。
2. Windows 已安裝 Node.js：執行 `START_LOCAL.cmd`。
3. 在 Chrome／Edge 開啟 **http://127.0.0.1:4173/**。

也可在專案資料夾執行 `node server.mjs`；或有 Python 時執行 `python -m http.server 4173 --bind 127.0.0.1`。無須建置、npm install、登入或 API 金鑰。使用支援 WebGL 2／WebAssembly 的現代瀏覽器；請透過 HTTP 開啟。

本次交付為可自行保存的 ZIP，沒有發布或推送到網站。若日後自行放到靜態主機，直接使用解壓縮內容，保留 `.nojekyll`；所有網址為相對路徑，可放在網站子目錄。

## 本版功能

- **地形比例**：森林、丘陵、田園、沙漠、鄉村、湖畔、雪地、火山選 1～4 種；滑桿與數字輸入自動維持合計 100%，可隨機環境或只重抽比例。公里數、地表、植被、小地圖及匯出紀錄共用相同設定。
- **63 款新自然模型**：58 款植物與 5 款岩石。依氣候／水岸安排，保留原始 UV、材質分件、透明裁切與色彩；18 張共用 PNG 避免重複下載與 GPU 貼圖，26 款樹／灌木另有 LOD1。
- **Rapier 行車**：650 kg 分為轉向架與簧上車體，保留原有功率與坡度受力；120 Hz 固定步長、CCD、彈簧阻尼與長距離座標重定基準。車體和動物隨懸吊移動，輪組保持軌道接觸位置。
- **實體物理測試**：「懸吊測試」施加垂直衝量；「前方 80 m 擋車器」可隨時放置／移除，倒車時放在倒車方向。撞擊後推桿自動回中立；左側顯示懸吊位移與撞擊次數。
- **保留既有內容**：3 台礦車、24 種動物、5～15 km 閉合路線、2／3 站、坡度上限、橋隧河谷、農田、近景草地、11 段 1,000～50,000 物件密度、獨立陰影及三種攝影機。

Rapier 使用受軌道約束的動力學，沿軌里程映射到三維路線。它實際求解受力、關節與碰撞；本版尚未模擬輪緣／鋼軌的完整三維接觸或脫軌。高密度是壓力測試選項，實際 FPS 取決於裝置、解析度、陰影與可視距離。

## 操作

↑／↓ 調整動力推桿，Space 回中立滑行；P 或 Esc 暫停。可拖曳畫面旋轉、滾輪縮放；C 循環追車／駕駛／全景。駕駛視角可拖曳轉頭。推桿平地刻度保留 120 km/h 前進、30 km/h 倒車上限；上下坡仍改變實際車速。分頁移到背景時會自動暫停。

標題改動地形、車種或坡度時會重建預覽；預覽用 2,000 物件，正式開始使用你選擇的密度。遊戲內「匯出測試紀錄」下載實際設定、路程比例、模型計數、Rapier 診斷與量測 JSON。
