# LOOP · 軌道試驗場 v13.0.0

本版以 GameAssets 的 `RailLoopLab-v12-20261119.zip` 為基礎，在標題加入三車直線競速。Three.js、Rapier、模型與貼圖都已隨包提供。

## 開啟

1. 完整解壓縮 ZIP，保留 `index.html`、`src`、`assets`、`vendor` 的相對位置。
2. Windows 已安裝 Node.js：執行 `START_LOCAL.cmd`。
3. 在 Chrome／Edge 開啟 **http://127.0.0.1:4173/**。

也可在專案資料夾執行 `node server.mjs`；或有 Python 時執行 `python -m http.server 4173 --bind 127.0.0.1`。無須建置、npm install、登入或 API 金鑰。使用支援 WebGL 2／WebAssembly 的現代瀏覽器；請透過 HTTP 開啟。

解壓縮內容可直接放到 GitHub Pages 等靜態主機，請保留 `.nojekyll`。所有網址使用相對路徑，支援網站子目錄。

## 軌道模式

- **直線競速 · 三車**可由標題的「軌道模式」選取。「每條賽道長度」可選 3～10 公里，每 1 公里一個選項。三條賽道各自使用這個三維長度。例如選 6 公里，每輛礦車從起點到終點都行駛 6 公里。
- **直線完賽**由三台車在對齊的起點倒數出發。各車按自身坡度受力，抵達終點時停車並記錄用時。所有車抵達後顯示名次，計時從倒數結束起算，顯示相同用時的車輛並列。設兩座車站時涵蓋起終點，設三座時在中途增加一站。
- **環狀巡行**的整條閉合路線長 5～15 公里，圈數可選 1 或 3 圈。1 圈用單車畫面，3 圈用等寬的左、中、右畫面，三車從始發站的對應月台出發，在同一條路線上持續繞行。

## 行車與場景

- **同步操控**用同一支推桿、同一組滑鼠手勢與相機選項控制三台車。每台車仍各自依所在坡度改變車速。原有面板共用，主速度表、下一站和物理測試以中車為準，各窗另顯示自己的車速。
- **渦輪推力**開啟後，每台車左右各展開一顆有旋轉扇葉的渦輪，向車尾噴出藍色火焰。前進時約 0.36 秒加入 30 km/h，關閉時平順退回一般速度，渦輪掉落並於 0.4 秒內消失。平地全速可達 150 km/h，倒車上限為 30 km/h。
- **環狀三圈的軌道間距**沿途變化，部分地段會分開繞過丘陵。相鄰軌道及高架橋上下層共用同一個地理位置的地形資訊。
- **立體交會**保有 6.2 m 軌面高差，多圈選擇 0 m 起伏時仍會生成必要的跨線坡。縱坡上限為 25‰，站區保持水平。啟用橋隧景觀時，生成器會在合適地段安排共用河谷、各圈的跨河橋及一段穿山隧道。隧道加寬、加高，橋欄往兩側移，給長耳動物和加裝渦輪的礦車預留空間。
- **站旁聚落**由外側站屋、步道和依地形挑選的住宅或工務建築組成。同一站區沿各圈設月台，共用站名與聚落。小地圖以較亮的線條標示目前所在圈，並標出跨線高架橋。

- **地形面積比例**可從森林、丘陵、田園、沙漠、鄉村、湖畔、雪地、火山選 1～4 種。比例合計 100%，以地圖的平面面積計算。地表顏色、起伏、植被和小地圖共用地理分布。地形交界有蜿蜒的混合帶，混合帶依權重分配面積。
- **63 款新自然模型**：58 款植物與 5 款岩石。依氣候／水岸安排，保留原始 UV、材質分件、透明裁切與色彩；18 張共用 PNG 避免重複下載與 GPU 貼圖，26 款樹／灌木另有 LOD1。
- **Rapier 行車**：650 kg 分為轉向架與簧上車體，保留原有功率與坡度受力；120 Hz 固定步長、CCD、彈簧阻尼與長距離座標重定基準。車體和動物隨懸吊移動，輪組保持軌道接觸位置。
- **實體物理測試**：「懸吊測試」施加垂直衝量；「前方 80 m 擋車器」可隨時放置／移除，倒車時放在倒車方向。撞擊後推桿自動回中立；左側顯示懸吊位移與撞擊次數。
- **壓力測試**可選 2／3 座車站、11 段 1,000～50,000 物件密度、獨立陰影、解析度、可視距離及三種攝影機。

## 陰影品質

打開標題的「壓力測試設定」，可分別開啟「車輛與設施陰影」及「地景物件陰影」，並選擇陰影品質。

| 品質 | 貼圖 | 投影寬度，地景陰影開啟時 |
| --- | --- | --- |
| 近景優先 | 1024 × 1024 | 160 公尺，保留礦車、設施和主要景物的投影 |
| 廣域高畫質 | 2048 × 2048 | 360 公尺，使用 v9 的陰影範圍 |

近景模式用較小的投影區域維持近處的取樣密度，部分小型石頭與地物以接收陰影為主。場景需要清楚的遠處投影時可選廣域高畫質。三車共用地圖與模型，每個畫面依鏡頭位置繪製可見物件與局部陰影。右側效能數字加總各畫面，匯出紀錄也提供各畫面的主畫面與陰影繪製量，適合固定種子和視角比較。

三車追車視角使用近景優先時，若同一張陰影貼圖能以相同的公尺／像素比例覆蓋三台車各自的投影範圍，就共用一次陰影繪製。當車輛分散、切換相機或使用廣域高畫質時，各視角照常更新自身的陰影。

## 距離與模型細節

- 距鏡頭約 90 公尺外的鋼軌每節用 60 個三角形，約 60 公尺外的枕木每根用 12 個。兩種細節共用原材質。枕木的高速過濾也作用於簡化模型。
- 近處短草每叢 7 片葉，中距為 2 片交叉葉。約 84 公尺開始淡出，108 公尺外由原有的地表草色接續。坡地穗草的遠距模型由 2,904 面減至 658 面。
- 橋欄立柱以 5.4 公尺間距排列，橫欄保持連續。隧道每 4 公尺的岩壁模組由 9,380 面減至 3,751 面，保有原來的進出口和車輛淨空。

Rapier 使用受軌道約束的動力學，沿軌里程映射到三維路線。它實際求解受力、關節與碰撞；本版尚未模擬輪緣／鋼軌的完整三維接觸或脫軌。高密度是壓力測試選項，實際 FPS 取決於裝置、解析度、陰影與可視距離。

## 操作

↑／↓ 調整動力推桿，Space 回中立滑行。右下角「渦輪推力」切換加速，倒車仍由推桿控制。P 或 Esc 暫停。可拖曳畫面旋轉、滾輪縮放，C 循環追車／駕駛／全景。追車縮放到最近會進入可自由轉頭的駕駛視角。推桿刻度表示一般模式在平地的速度，上下坡與渦輪會改變實際車速。分頁移到背景時會自動暫停。

標題改動地形、車種、軌道模式、路長、圈數或坡度時會重建預覽。預覽用 2,000 物件，正式開始時使用所選的密度。遊戲內「匯出測試紀錄」可下載實際設定、每台車的速度及 Rapier 診斷、路線和月台里程、地圖面積比例和模型計數。直線模式另記每條賽道的長度和各車完賽用時。
